# AI skills

Claude Code skills, one folder per skill.

| Skill | Use |
|---|---|
| [erp-ui](erp-ui/SKILL.md) | Build, edit or critique an ERP, admin or app UI: calm, dense, rounded, no clutter. Say "erp ui". |

## Install

Copy a skill folder into `~/.claude/skills/` (all projects) or `.claude/skills/` in a repo:

```sh
git clone https://github.com/JoshD94/ai-skills.git
cp -r ai-skills/erp-ui ~/.claude/skills/
```
