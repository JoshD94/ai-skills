# AI skills

Claude Code skills, one folder per skill.

| Skill | Use |
|---|---|
| [erp-ui](erp-ui/SKILL.md) | Build, edit or critique an ERP, admin or app UI: calm, dense, rounded, no clutter. Say "erp ui". One product owner's taste as hard rules (`taste.md`), their critiques in their own words (`feedback.md`, grows with every review), 93 chosen UI/UX principles (`principles.md`), and reference screenshots with a self-audit (`references/`). Live showcase: [design.alorawork.com](https://design.alorawork.com) ([source](https://github.com/taskflowdev1/alora-design)). |

## Install

Copy a skill folder into `~/.claude/skills/` (all projects) or `.claude/skills/` in a repo:

```sh
git clone https://github.com/JoshD94/ai-skills.git
cp -r ai-skills/erp-ui ~/.claude/skills/
```
